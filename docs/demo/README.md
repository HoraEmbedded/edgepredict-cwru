# Demonstration materials

This folder contains screenshots and terminal captures of the EdgePredict-CWRU system running on the Raspberry Pi 4.

## Dashboard screenshots


- `dashboard_light_105_innerrace.png`: light theme, InnerRace scenario
- `dashboard_97_normal.png`: Normal scenario, green status
- `dashboard_118_ball.png`: Ball fault scenario
- `dashboard_130_outerrace.png`: OuterRace fault scenario
- `dashboard_scenario_selector.png`: zoom on the scenario selector

## Terminal captures

- `terminal_systemctl_status.png`: systemd service active
- `terminal_api_state.png`: JSON response from `/api/state`
- `terminal_api_model.png`: JSON response from `/api/model`
- `terminal_htop.png`: CPU and memory usage during inference
