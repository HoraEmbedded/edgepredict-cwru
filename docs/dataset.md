# CWRU Dataset

The CWRU Bearing Dataset is a reference dataset for bearing fault diagnosis.

## Classes used in this project

- Normal
- Inner Race fault
- Outer Race fault
- Ball fault

## Sampling

- Sampling frequency: 12 kHz
- Window size: 1024 points
- Overlap: none

## Files

12 files are used, 3 per class.

The raw .mat files are stored in data/raw and are not versioned on GitHub.
